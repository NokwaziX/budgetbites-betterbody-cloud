# PartyRock Prototype

## BudgetBites – BetterBody

BudgetBites – BetterBody is an AI-powered meal planning concept originally
created using Amazon PartyRock.

The application helps users with:

- Budget-friendly meal suggestions
- Fridge and pantry meal ideas
- Calorie and macro estimates
- Weight goal inputs
- Meal photo analysis
